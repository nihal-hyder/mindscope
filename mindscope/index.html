          About
          
How MindScope works

          

            MindScope is an educational project that estimates a student mental health score from everyday
            habits, using a model trained on student survey data.
          

        


        

          

            
            
What it does

            
Takes a short profile of your routine and returns a numerical score predicted by a trained model — a way to explore how lifestyle patterns relate to wellbeing.

          

          

            
            
What it analyzes

            
Twelve features: age, gender, country, academic level, platform, purpose of use, screen time, phone unlocks, study, physical activity, sleep and stress level.

          

          

            
            
Machine learning

            
A scikit-learn pipeline scales numeric inputs, log-transforms study hours, encodes categories, then feeds a Random Forest regressor.

          

          

            
            
FastAPI backend

            
Predictions are served by a FastAPI endpoint. Pydantic validates every request before it ever reaches the model.
